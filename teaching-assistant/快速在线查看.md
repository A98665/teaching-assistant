# 🚀 快速在线查看 - 无需安装Node.js

## 方法一：使用 StackBlitz（最简单，推荐⭐⭐⭐⭐⭐）

### 步骤：

1. **打开 StackBlitz**
   - 访问：https://stackblitz.com/
   - 点击右上角 "Sign in"（可选，不登录也能用）

2. **创建新项目**
   - 点击 "Create a new project"
   - 选择 "Vite" 模板
   - 或者直接访问：https://stackblitz.com/fork/vitejs-vite-react-ts

3. **导入项目文件**
   
   在 StackBlitz 的文件树中，按以下步骤操作：
   
   **a. 删除默认文件**（保留 node_modules 和 package.json）
   
   **b. 更新 package.json**，替换为以下内容：
   ```json
   {
     "name": "teaching-assistant",
     "private": true,
     "version": "0.0.0",
     "type": "module",
     "scripts": {
       "dev": "vite",
       "build": "tsc && vite build",
       "preview": "vite preview"
     },
     "dependencies": {
       "react": "^18.2.0",
       "react-dom": "^18.2.0",
       "react-icons": "^4.12.0"
     },
     "devDependencies": {
       "@types/react": "^18.2.43",
       "@types/react-dom": "^18.2.17",
       "@vitejs/plugin-react": "^4.2.1",
       "autoprefixer": "^10.4.16",
       "postcss": "^8.4.32",
       "tailwindcss": "^3.4.0",
       "typescript": "^5.2.2",
       "vite": "^5.0.8"
     }
   }
   ```
   
   **c. 创建 tailwind.config.js**：
   ```js
   export default {
     content: ["./index.html", "./src/**/*.{js,ts,jsx,tsx}"],
     theme: { extend: {} },
     plugins: [],
   }
   ```
   
   **d. 创建 postcss.config.js**：
   ```js
   export default {
     plugins: { tailwindcss: {}, autoprefixer: {} },
   }
   ```
   
   **e. 复制所有 src 文件夹下的文件**
   - 从您的项目文件夹 `C:\Users\lenovo\teaching-assistant\src\` 复制所有文件
   - 粘贴到 StackBlitz 的 `src` 文件夹中

4. **等待自动安装和启动**
   - StackBlitz 会自动安装依赖
   - 几秒钟后，右侧预览窗口会自动显示您的应用

5. **查看界面**
   - 右侧就是运行中的应用
   - 可以实时编辑代码，自动刷新

## 方法二：使用 CodeSandbox（备选方案）

1. 访问：https://codesandbox.io/
2. 点击 "Create Sandbox"
3. 选择 "Vite" 模板
4. 按照方法一的步骤导入文件
