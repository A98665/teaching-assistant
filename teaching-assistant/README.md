# 教学辅助系统

一个基于 React + TypeScript + Tailwind CSS 的教学辅助系统前端界面，用于接收教学方案、展示分析结果和教学资源、以及评估教学资源。

## 功能特性

### 板块一：教学方案输入区
- ✅ 多种输入方式：文本输入、文件上传、URL导入、模板选择
- ✅ 文件拖拽上传支持
- ✅ 文件类型验证
- ✅ 字符计数显示
- ✅ 输入方式切换动画

### 板块二：分析结果与资源展示区
- ✅ 分析结果文本展示（模拟AI分析输出）
- ✅ 教学资源列表展示（PPT、视频、图片、文档）
- ✅ 资源类型筛选功能
- ✅ 资源点击选择功能
- ✅ 加载骨架屏

### 板块三：教学资源评估区
- ✅ 交互式星级评分组件（1-5星）
- ✅ 评估评论输入
- ✅ 评估历史记录展示
- ✅ 评估统计（平均分、评估数量）

## 技术栈

- **框架**: React 18 + TypeScript
- **样式**: Tailwind CSS
- **构建工具**: Vite
- **图标库**: react-icons

## 布局设计

系统采用三栏左右分栏布局：

- **左侧栏（30%）**: 教学方案输入区
- **中间栏（50%）**: 分析结果与资源展示区（上下分栏）
- **右侧栏（20%）**: 教学资源评估区

响应式设计：
- 大屏幕（≥1024px）：三栏布局
- 小屏幕（<1024px）：上下堆叠布局

## 使用说明

1. **输入教学方案**：在左侧面板选择输入方式（文本/文件/URL/模板），输入内容后点击"提交分析"
2. **查看分析结果**：提交后，中间面板会显示分析结果和推荐的教学资源
3. **选择资源**：点击资源列表中的任意资源项进行选择
4. **评估资源**：在右侧面板对选中的资源进行评分和评论
