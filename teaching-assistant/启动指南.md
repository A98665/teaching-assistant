# 教学辅助系统 - 启动指南

## 📋 查看界面的具体流程

### 前置要求
- 已安装 Node.js (版本 14 或更高)
- 已安装 npm 或 yarn 包管理器

### 步骤 1：打开项目目录

在 PowerShell 或命令提示符中执行：

```powershell
cd C:\Users\lenovo\teaching-assistant
```

或者直接在文件资源管理器中打开：
```
C:\Users\lenovo\teaching-assistant
```

### 步骤 2：安装项目依赖

```powershell
npm install
```

**预期输出**：会看到依赖包下载和安装的进度，完成后会显示类似：
```
added 123 packages in 2m
```

**如果遇到问题**：
- 如果 npm 命令不可用，请先安装 Node.js：https://nodejs.org/
- 如果下载慢，可以使用国内镜像：
  ```powershell
  npm install --registry=https://registry.npmmirror.com
  ```

### 步骤 3：启动开发服务器

```powershell
npm run dev
```

**预期输出**：会看到类似以下信息：
```
  VITE v5.0.8  ready in 500 ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
  ➜  press h + enter to show help
```

### 步骤 4：在浏览器中打开

1. 复制终端中显示的本地地址（通常是 `http://localhost:5173/`）
2. 打开浏览器（Chrome、Edge、Firefox 等）
3. 在地址栏粘贴并访问该地址

**或者直接点击终端中的链接**（如果终端支持）

### 步骤 5：使用界面

界面加载后，您会看到：

1. **左侧面板**：教学方案输入区
   - 可以切换不同的输入方式（文本/文件/URL/模板）
   - 输入内容后点击"提交分析"按钮

2. **中间面板**：分析结果与资源展示
   - 上方显示分析结果
   - 下方显示推荐的教学资源列表
   - 点击资源项可以选择它

3. **右侧面板**：资源评估区
   - 选择资源后可以在这里进行评分和评论
   - 查看评估历史和统计信息

### 🛑 停止开发服务器

在终端中按 `Ctrl + C` 停止服务器

### ❓ 常见问题

**Q: 端口 5173 已被占用怎么办？**
A: Vite 会自动尝试下一个可用端口（如 5174），查看终端输出中的实际地址即可。

**Q: 页面显示空白？**
A: 
- 检查浏览器控制台是否有错误（F12）
- 确认所有依赖都已正确安装
- 尝试清除浏览器缓存后刷新

**Q: 样式没有加载？**
A: 
- 确认 Tailwind CSS 配置正确
- 检查 `src/index.css` 文件是否存在
- 重启开发服务器

**Q: 如何修改端口？**
A: 在 `vite.config.ts` 中添加：
```typescript
export default defineConfig({
  plugins: [react()],
  server: {
    port: 3000  // 修改为您想要的端口
  }
})
```
